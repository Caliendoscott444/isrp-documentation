# Iowa State Roleplay — Mintlify Documentation

This repository is prepared for deployment with Mintlify.

## Connect it to Mintlify

1. Push these files to the root of your GitHub repository.
2. Sign in to Mintlify and connect your GitHub account.
3. Create a documentation site and select `Caliendoscott444/isrp-documentation`.
4. Set the documentation root to `/` (repository root), if prompted.
5. Deploy the site from Mintlify.

Mintlify uses `docs.json` for site configuration and MDX pages for content.
The previous MkDocs configuration and GitHub Pages workflow are intentionally
not included in this version.
